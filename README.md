#  Phishing Attack Simulation using Cisco Packet Tracer

## Project Overview
This project simulates a **phishing attack** scenario in a controlled environment using **Cisco Packet Tracer**.

##  Files Included
- `NA - Activity 2.pdf` — Complete project report
- `NA - A2.pkt` — Cisco Packet Tracer simulation file

##  Tools Used
- Cisco Packet Tracer
- HTML (for fake webpage)
- Email Server configuration

##  Features Demonstrated
- Fake phishing email sent to victim
- Victim redirected to fake login page
- Credential capture and analysis
